# Datacake-Payload-Decoder

All rights reserved to MycoLutions GmbH. This is a script I developed as an IoT and Sensor Systems Engineering intern.

Configured in Datacake to decode the raw AM103 binary payload into the named measurements used throughout the dashboard.  This script is written in JavaScript. Used in the IoT platform, Datacake: which is the current dashboard used by MycoLutions GmbH. Find it under the particular device > Configuration > Hardware &amp; Products > Payload Decoder
